# AI Lab Cycle 2

A Python menu-driven collection of Experiments 8–13 covering data cleaning and visualization, prompt engineering, prompting techniques, technical content generation, and an AI-powered study assistant.

## Requirements

- Python 3.10 or newer
- NumPy
- pandas
- Matplotlib

## Run

```bash
python ai_lab_cycle_2.py
```

Or run each experiment separately:

```bash
python experiment_08_data_cleaning_eda.py
python experiment_09_data_visualization.py
python experiment_10_prompt_design_evaluation.py
python experiment_11_prompting_techniques.py
python experiment_12_technical_generation.py
python experiment_13_study_assistant.py
```
